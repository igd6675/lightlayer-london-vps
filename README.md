## 线路：三网直连，但路由是 Global 不是 CN2

有篇 2025 年的教程把伦敦写成“CN2 线路”，这个说法和实测对不上。2024 年 7 月的 traceroute 记录显示，伦敦机房走的是英国 COLT（AS8220）的国际线路，2026 年的英文评测也把伦敦归到 Global 路由，和香港、东京的 Premium CN2 不是一个类别。规划时按 Global 路由的预期来，别指望它在中国大陆访问上和香港 CN2 一个水平。

实测的方向大致是这样：

- **去程**：电信直连英国伦敦，联通先到德国法兰克福再转英国，移动直连伦敦。
- **回程**：联通从延迟判断走 AS4837 直连回国，移动走 CMI 直连，电信部分方向直连、部分线路未能判定。
- **延迟**：国内部分地区 ping 平均约 **217ms**。对伦敦机房来说这个数字算正常，直连没问题，但它不是优化线路，晚高峰的稳定性要看具体省份。

另一个容易被忽略的限制：这条线**不支持 IPv6**。如果你的业务需要 IPv6 出口（部分支付风控、邮件投递、或者对接只给 AAAA 记录的服务），这一条直接排除了它。

## IP 才是这条线的主角

“双 ISP”这个词在中文测评里出现得多，讲清楚的少。它的判定来源是 ipinfo 对这条 IP 的两个字段：ASN 归属 AS8220 COLT Technology Services，标记类型为 isp；company 字段是 Tianfeng (Hong Kong) Communications Limited，类型同样标记为 isp。两个字段都是 ISP 类型，数据库就显示为双 ISP。这代表的是 IP 在数据库里的画像，不代表它由某家英国宽带运营商直接分配给你。

这个画像有什么实际用处？跨境电商平台、流媒体、社交账号在做风控时，判断一个访问者是不是本地真实用户，看的就是这类 IP 归属数据。英国本土属性的住宅类 IP，在这类判定里比机房 IP 更接近普通家庭用户。2024 年的测评里，测评方给出的结论是英国本地流媒体基本都能解锁，跨区域的部分服务则不一定。

单机最多 20 个 IPv4，是这条线最容易被低估的能力。多店铺、多账号运营的常规做法是每个账号配一个独立出口 IP，避免因为 IP 复用被平台关联。20 个 IP 意味着在一台机器上就能铺开 20 个独立出口，不用买 20 台 VPS，管理成本和账单都省下来。只需要一两个 IP 的话，$19 的入门款完全够用，不必为了“最多 20 个”这个上限多付钱。加购 IP 的具体单价在配置页里显示，公开资料里没有单独列出。
